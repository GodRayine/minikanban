# Мини-канбан

Простая доска задач с тремя колонками — «Не начато», «В процессе», «Готово» — для компьютера с Windows и телефона с Android. Компьютер хранит основную копию доски, телефон синхронизируется с ним по домашнему Wi-Fi. Интернет, учётные записи и облако не нужны: данные не покидают вашу сеть.

## Установка на компьютер (Windows 10/11)

1. Скопируйте **всю папку** `minikanban\build\windows\x64\runner\Release` в удобное место (например, `C:\Программы\Мини-канбан`). Нужна папка целиком: рядом с `minikanban.exe` лежат библиотеки и папка `data`, без них программа не запустится.
2. Запустите `minikanban.exe`.
3. При первом запуске Windows покажет окно брандмауэра «Разрешить этому приложению доступ к сетям?». Отметьте **и частные, и общедоступные сети** и нажмите «Разрешить доступ». Без этого телефон не сможет подключиться.
   - Работа в сети с профилем «Общедоступная» поддерживается — менять профиль сети не нужно, достаточно разрешения в брандмауэре.
   - Если окно не появилось или вы нажали «Отмена»: откройте в программе «Подключить телефон». Если доступ не разрешён, там появится подсказка с кнопкой **«Разрешить в брандмауэре»** — Windows попросит подтверждение администратора и добавит правило. Когда всё в порядке, на этом экране написано «Брандмауэр Windows: Доступ разрешён».
   - Правило брандмауэра привязано к пути к `minikanban.exe`. **Если вы перенесёте или переименуете папку с программой, Windows спросит разрешение заново** (или воспользуйтесь той же кнопкой).

## Установка на телефон (Android 15 и новее)

1. Скопируйте на телефон файл `minikanban\build\app\outputs\flutter-apk\app-release.apk` (по кабелю, через мессенджер или облако) и откройте его.
2. Android попросит разрешить установку из этого источника — разрешите и нажмите «Установить».
3. При первом запуске приложение попросит доступ к камере (для сканирования QR-кода) и к устройствам в локальной сети (для связи с компьютером) — разрешите оба.

С компьютера, если включена отладка по USB: `adb install -r app-release.apk`.

## Привязка телефона к компьютеру

Телефон и компьютер должны быть подключены к одной сети Wi-Fi.

**По QR-коду (обычный способ)**

1. На компьютере нажмите «Подключить телефон» — появится QR-код. Код действует 5 минут и обновляется сам.
2. На телефоне нажмите «Подключить к компьютеру» и наведите камеру на код.
3. Через несколько секунд на компьютере появится «Телефон подключён», а доски сравняются.

**Вручную (если камера не работает)**

1. На экране сканера на телефоне выберите «Ввести адрес вручную».
2. Введите адрес компьютера (строка «Адрес в локальной сети», например `192.168.1.20:47321`) и код, показанный под QR-кодом. Вместо этого можно вставить строку подключения целиком (кнопка «Скопировать строку подключения» на компьютере).

**Отвязка.** На компьютере: «Подключить телефон» → «Связанные устройства» → «Отвязать». На телефоне: «Настройки» → «Отвязать». Задачи остаются на обоих устройствах; чтобы подключиться снова, отсканируйте новый QR-код.

## Как работает синхронизация

Телефон сам связывается с компьютером:

- при открытии приложения и при возвращении в него;
- каждые 5 минут, пока приложение на экране;
- через несколько секунд после любой правки;
- в фоне — примерно раз в 15 минут (точное время выбирает Android; в режиме экономии заряда — реже);
- сразу по кнопке синхронизации на доске или «Синхронизировать сейчас» в настройках.

Если компьютер выключен или телефон вне дома, правки копятся на телефоне и уйдут при следующей связи. Если одну и ту же карточку изменили на обоих устройствах, побеждает более поздняя правка. Статус виден на плашке вверху доски: «Синхронизировано · 3 мин назад», «Нет связи с ПК», «Отвязано от ПК».

Компьютер телефон находит сам, даже если у компьютера сменился IP-адрес: сначала пробует последний удачный адрес, затем ищет компьютер в сети по имени службы, затем по сетевому имени и по адресам из QR-кода.

## Трей и автозапуск

- Закрытие окна крестиком **не завершает** программу: она сворачивается в область уведомлений (трей) и продолжает принимать подключения телефона. Щелчок по значку открывает окно, правый щелчок — меню «Открыть Мини-канбан» / «Выход».
- Чтобы закрыть программу совсем: «Выход» в меню значка или «Настройки» → «Выйти из приложения». Пока программа закрыта, телефон показывает «Нет связи с ПК».
- «Настройки» → «Запускать вместе с Windows» — программа будет стартовать свёрнутой в трей при входе в систему.
- Повторный запуск `minikanban.exe` не создаёт вторую копию, а открывает окно уже работающей.

## Типичные проблемы

| Что видно | Что делать |
|---|---|
| Телефон пишет «Нет связи с ПК» или не подключается при привязке | Проверьте, что программа на компьютере запущена (значок в трее) и оба устройства в **одной** сети Wi-Fi. |
| На экране «Подключить телефон» подсказка про брандмауэр | Нажмите «Разрешить в брандмауэре» и подтвердите запрос Windows. Так бывает после переноса папки с программой или если при первом запуске нажали «Отмена». |
| Сеть в Windows отмечена как «Общедоступная» | Это нормально и поддерживается. Нужно только, чтобы в брандмауэре доступ был разрешён и для общедоступных сетей (см. выше). |
| Гостевой Wi-Fi, сеть в кафе или гостинице | Такие сети часто изолируют устройства друг от друга («изоляция клиентов») — телефон не увидит компьютер, что бы вы ни настраивали. Используйте домашнюю сеть или раздайте Wi-Fi с телефона на компьютер. |
| На телефоне включён VPN | VPN может уводить трафик мимо локальной сети. Выключите его или добавьте «Мини-канбан» в исключения VPN-приложения. VPN на компьютере обычно не мешает: его адреса программа не использует. |
| У компьютера сменился IP-адрес | Обычно телефон находит его сам за несколько секунд. Если нет — в настройках на телефоне удерживайте строку с именем компьютера (принудительный поиск заново) или привяжите телефон ещё раз по QR-коду. |
| Сканер пишет «Нужен доступ к камере» | Нажмите кнопку на этом экране и разрешите камеру, либо выберите «Ввести адрес вручную». |
| Телефон пишет «Отвязано от ПК» | Его отвязали на компьютере. «Настройки» → «Подключить заново». |
| «Ошибка сертификата ПК» | На компьютере удаляли данные программы. Привяжите телефон заново. |
| Фоновая синхронизация редкая | Android откладывает фоновые задачи при экономии заряда. Откройте приложение — оно синхронизируется сразу. |

## Где лежат данные

- **Компьютер:** `%APPDATA%\com.minikanban\Мини-канбан\` — файл `minikanban.db` (доска и список привязанных телефонов), `server_cert.pem` и `server_key.pem` (сертификат для защищённого соединения). Для резервной копии достаточно скопировать эту папку при закрытой программе. Если удалить её, все телефоны придётся привязать заново.
- **Телефон:** во внутренней памяти приложения (`/data/data/com.minikanban.minikanban/`), без root недоступно. Данные удаляются вместе с приложением; копия остаётся на компьютере.

Соединение между телефоном и компьютером шифруется (HTTPS), телефон проверяет сертификат компьютера, запомненный при привязке.

## Сборка из исходников

Нужны: Flutter 3.50+, Visual Studio Build Tools 2022 (C++ и ATL), Android SDK (платформа 37, build-tools 35, NDK 28) и JDK 17.

Исходники лежат в `Документы\канбан\minikanban`, но **собирать нужно через путь без кириллицы** — ссылку `C:\src\minikanban` (кириллица в пути ломает сборку и под Windows, и под Android). Создать ссылку, если её нет:

```powershell
New-Item -ItemType Junction -Path C:\src\minikanban -Target "$env:USERPROFILE\Documents\канбан\minikanban"
```

Сборка:

```powershell
$env:Path = "C:\Program Files\Git\cmd;$env:USERPROFILE\dev\flutter\bin;$env:Path"
Set-Location C:\src\minikanban

flutter pub get
flutter analyze
flutter test

flutter build windows --release   # build\windows\x64\runner\Release\
flutter build apk --release       # build\app\outputs\flutter-apk\app-release.apk
```

Перед сборкой под Windows закройте работающую программу («Выход» в трее), иначе `minikanban.exe` занят. В `android\gradle.properties` свойство `minikanban.asciiRoot` должно указывать на ту же ASCII-ссылку.
